# Visual Direction — v1.7.9.1

The approved benchmark is cinematic illustrated fantasy: natural daylight above ground, rich but believable materials, dimensional light, strong environmental depth, and consistent Rowan design.

The high-end title/UI concepts generated during the polish session are **art-direction references**, not literal gameplay screenshots. Their painted-in buttons and labels are not shipped as interactive controls. Gameplay UI remains live HTML so every visible control is functional and accessible.

Permanent rules:
- No pixel-like/cartoon holdovers beside cinematic scenes.
- Rowan stays visually consistent in clothing, hair, proportions and facing direction.
- Exterior time-of-day must agree with narrative context.
- Scene art, description, hotspots and state logic are reviewed as one unit.
- If state-specific art would require an obvious pasted/flat overlay, keep the clean base artwork and communicate the state through the live UI until a proper bespoke redraw exists.
